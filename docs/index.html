The learning loop

  1. See and try a concrete problem
  2. Name the idea after experience
  3. Practise without answer leakage
  4. Transfer to a changed context
  5. Return for delayed review

More than a long answer.

One local classroom

Lessons, feedback, references, and progress stay organized in an inspectable HTML workspace.

Evidence before mastery

Understanding is checked through independent retrieval, application, transfer, and delayed review.

Hints without leakage

Retries keep the original task and earliest error while revealing only the next useful hint.

Progress across sessions

The learner owns the `.mastery/` record; no hosted account or remote database is required.

Purpose-built labs

A second cooperating Skill creates code exercises, simulations, visual explanations, and accessible fallbacks.

Honest compatibility

Packaging, engine behavior, live-agent behavior, usability, and learning outcomes are reported as separate evidence levels.

One-prompt install

Give the repository to your agent.

Install Mastery Tutor from https://github.com/fanfanfanfanfan626/mastery-tutor. Read AI_INSTALL.md first, detect the current host, install both required Skills, preserve every .mastery learner workspace, and do not claim success until that host's verification steps pass.

Codex uses the complete plugin adapter. Other compatible Agent Skills hosts install `mastery-coach` and `mastery-tool-creator` together.

Release status: source version 0.5.0 is a release candidate. The latest tagged release is v0.4.1 under the former Mastery Learning identity. Version 0.5.0 will be tagged only after its required live-conversation evidence gate passes.
