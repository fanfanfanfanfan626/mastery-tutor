3 个问题 · 不用安装 · 不用账号

它在执行规则，还是从例子中学习？

先判断，再看反馈，最后换个场景试试。这是 Mastery Tutor 教学循环的一小段。

这是预先编写的交互样例，不会调用 AI，不保存答案，不上传你的输入；不代表完整产品或学习效果验证。

先看一对例子

规则筛选器

程序员写下：“邮件里出现‘免费中奖’，就标为可疑。”判断标准直接由人指定。

学习型筛选器

给模型许多已标注的正常邮件和垃圾邮件，让它调整参数，学习哪些特征有助于分类。

区别不在于软件是否复杂、是否用 Python，甚至不在于准确率高低。关键是：判定规则由人直接写下，还是参数从数据中学来？

现在由你判断

练习加载后将在这里显示；也可以直接阅读本页例子与总结。

带走一个判断方法

问：“系统的判断方式怎样产生？”人直接指定的是规则；通过样本调整参数的是学习。实际产品可能同时使用两种方式。

答对这三个预设问题不能证明掌握。真正的导师还需要新情境、独立解释和间隔复习，而不是只记录一次正确答案。

The idea, in English

A rule-based system follows decision rules specified by people. A learned model fits parameters from examples. Accuracy, complexity, and programming language alone do not distinguish them. Real applications can combine both.

This prepared three-question demo illustrates prediction, feedback, and transfer. It is not a live AI tutor, does not grade mastery, and does not store or send answers.
